# College Assignment Website

A collaborative website development project created as part of a college assignment. The project is built using HTML, CSS, and JavaScript, with the goal of developing and improving a functional, user-friendly website.

## Project Overview

This repository contains the source code and resources used to develop the website. It serves as a shared workspace where team members can contribute code, improve the design, and track development progress.

## Technologies Used

- **HTML5** – Structure and content of the website.
- **CSS3** – Styling, layout, and visual design.
- **JavaScript** – Interactivity and dynamic functionality.
- **Git & GitHub** – Version control and collaboration.

## Project Structure

```text
College-assignment-final/
│
├── Innovative/          # Innovative assignment files
├── Resources/           # Project resources and assets
├── index.html           # Main webpage
├── History.html         # History webpage
├── styles.css           # Main stylesheet
├── historystyles.css    # Styles for the history webpage
├── app.js               # JavaScript functionality
└── README.md            # Project documentation
```

## Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/Prasit20/College-assignment-final.git
```

### 2. Navigate to the project directory

```bash
cd College-assignment-final
```

### 3. Run the website

Open `index.html` in your web browser.

For a better development experience, you can use the **Live Server** extension in Visual Studio Code.

## Collaboration

This project is developed collaboratively using Git and GitHub.

Team members can contribute by:

- Developing new pages and features.
- Improving the website's layout and styling.
- Fixing bugs and testing functionality.
- Updating documentation and project resources.

### Recommended workflow

1. Pull the latest changes from the shared repository.
2. Create a separate branch for your work.
3. Make changes and test them locally.
4. Commit and push your changes.
5. Merge changes into the main branch after reviewing them.
